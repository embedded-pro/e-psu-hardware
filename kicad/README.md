# e-psu rev A: KiCad project

KiCad 7 project. Open `e-psu.kicad_pro` in KiCad 7 or newer.

- `e-psu.kicad_sch` and the sheet files hold the schematic (rev A1); `e-psu.pdf` has every sheet.
- `e-psu.kicad_pcb` is the 4-layer, 100 × 100 mm board. It is generated by `../pcb/make_board.py`; see `../pcb/README.md`.
- `e-psu.pretty` holds the project footprints. **U201 is provisional.**

| Page | Sheet | Contents |
|---|---|---|
| 1 | Root | Block overview, power flow, ground domains |
| 2 | Power input & housekeeping rails | 30 V input protection, LMR16006X 5 V buck, +3V3 / +3.3VA / +5VA, VOP / VNEG |
| 3 | Tracking buck pre-regulator | LM76003; VPRE = VOUT + 1.5 V by DAC injection into FB |
| 4 | Linear CV/CC stage & setpoint DAC | IRFP260N pass FET, INA293 3 A shunt, OPA2192 CV/CC loops, OPA192 sense buffer, DAC80502 |
| 5 | Current measurement & auto-ranging | 1 R / 100 R shunt ladder, bypass FETs, INA190 range amps, isolated gate-drive island |
| 6 | Pass-through & output switch | 2 mΩ / INA281 10 A path, mode relay, back-to-back FET output switch, terminals |
| 7 | MCU, debug & user interface | STM32G474RET6 pin map, SWD, LEDs, button, board NTC |
| 8 | Isolated USB | USB-C, USBLC6, ADuM3160 |

Symbols that are not in the standard KiCad libraries are in `e-psu.kicad_sym`. `sym-lib-table` links it into the project. Every part has a Footprint field. Most parts also have LCSC and MPN fields for JLCPCB assembly.

## Before ordering

1. **Run ERC in KiCad.** The netlist was checked against the design intent, but KiCad's own ERC has not been run on it.
2. **Replace the U201 footprint.** The one in `e-psu.pretty` is a placeholder drawn without the package drawing.
   - The real one is TI RNP0030B (WQFN-30, 6 × 4 mm). Get it from TI or from LCSC/EasyEDA (C470958) and save it as `e-psu:TI_RNP0030B_WQFN-30`.
   - Then re-run `../pcb/make_board.py --own`, or re-route the buck corner by hand.
3. **Check these pinouts against the maker's drawings:**
   - K501 HF115F: the pins are mapped onto the KiCad Schrack RT1 footprint.
   - PS401 B0505S.
   - U502 VOM1271: pin 4 is assumed to be + and pin 3 to be −.
4. **Board fab options:** 4 layers, 1 oz inner copper, and a check of the CPL rotations in JLC's preview. See `../pcb/README.md`.
5. **Check the island ground symbol.** On page 5, the ground-style "VFORCE" symbol is the island reference, and it is the same net as the force node. On page 8, GND_USB is the PC-side ground.
